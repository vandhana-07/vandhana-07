## 📂 Featured Projects

### 🛰️ [COLDSTART — SEDHACKS '26](https://github.com/vandhana-07/COLDSTART)

A flight-day power and thermal autonomy planner for near-space payloads. It models coupled heat and power, searches for viable designs within cost and weight limits, and supports sensitivity and stress-scenario analysis.

**Tech:** Python, HTML, CSS, JavaScript

### 📄 [Intelligent Document Understanding Platform](https://github.com/vandhana-07/Intelligent-document-platform)

A dual-mode RAG application for asking source-grounded questions about PDF, DOCX, and TXT files. It supports Groq cloud inference and a local Ollama mode, with local embeddings and traceable source passages.

**Tech:** React, FastAPI, Sentence Transformers, ChromaDB, SQLite, Groq, Ollama

### 🏙️ [UrbanShield](https://github.com/vandhana-07/UrbanShield)

A Chennai flood-risk decision-support prototype that combines public rainfall, inundation, hotspot, and hazard data to prioritize infrastructure, allocate response resources, and explore what-if scenarios. Risk estimates are evidence-based; the current prototype is not a trained predictive ML model.

**Tech:** Python, Streamlit, Flask, Google OR-Tools, SQLite

### 📈 [India Unemployment Analysis & Dashboard](https://github.com/vandhana-07/unemployment-analysis)

An analysis of state-wise monthly unemployment rates in India from 2019–2020, including COVID-19 impacts. The project combines a Python/Jupyter analysis pipeline with an interactive Next.js dashboard.

**Tech:** Python, Pandas, Jupyter Notebook, Next.js, React, TypeScript

### 🚗 [Car Price Prediction](https://github.com/vandhana-07/car-price-prediction)

A used-car price prediction project that compares Linear Regression, Random Forest, and Gradient Boosting on a Kaggle dataset.

**Tech:** Python, Pandas, NumPy, Scikit-learn
